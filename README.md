# Java — Ruta de aprendizaje

Ejercicios y proyectos del módulo de **Java**: desde los fundamentos hasta programación orientada a objetos, principios **SOLID** y **patrones de diseño**.

## Contenido

| Carpeta | Tema |
|---|---|
| `Dia 1` … `Dia 5` | Ejercicios diarios de fundamentos y POO |
| `SOLID` | Un ejemplo por principio: Single Responsibility, Open/Closed, Liskov, Interface Segregation y Dependency Inversion |
| `Patrones Creacionales` | Patrones creacionales |
| `Patrones estructurales` | Patrones estructurales |
| `Patrones de comportamiento` | Patrones de comportamiento |
| `Banco` | Proyecto de práctica: simulación bancaria |
| `Carrera` | Proyecto de práctica |
| `baloncesto`, `ejercicio` | Ejercicios adicionales |
| `CorreccionQuiz` | Corrección del quiz del módulo |

Los proyectos están hechos en **NetBeans** (Ant); se pueden abrir directamente desde el IDE.

## Stack

`Java` · `POO` · `SOLID` · `Patrones de diseño`
